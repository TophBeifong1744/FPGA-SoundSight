# 板端部署

- `artifacts/screen_s2/`：配套的 bit、HWH 和 XSA。
- `artifacts/soundsight_pynq_3d_speaker.zip`：完整运行包，包含声纹模型和 ARM 推理库。
- `artifacts/soundsight_screen_product_p1.zip`：触屏应用及自动启动服务安装包。
- `scripts/`：板端命令入口；`instructions/`：屏幕与硬件操作说明。
- `guides/`：安装、标定、模式切换、声纹录入与日志分析步骤。

从[板端安装说明](guides/public-deployment.md)开始。首次使用录入目标用户并设置参数，再进行声音跟随或声纹跟随测试。
