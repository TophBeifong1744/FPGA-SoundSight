# 现有工程输入审阅

只读实际配套产物，不从项目名推测平台。

| 输入 | 核对内容 |
|---|---|
| bit/HWH/XSA/BD配方 | 同候选关系、器件、IP实例及参数 |
| 时钟/复位 | 参考频率、实际分频、输出域、极性和保留域 |
| 寄存器 | 地址、副作用、锁定/消费、清错及STOP |
| DMA | 收发方向、SG/simple、DRE、宽度、长度、TLAST、缓存 |
| 软件 | 实际Python/PYNQ/驱动、分配器及进程职责 |
| 证据 | 版本、运行配置、真实输入、计时边界 |

S2MM不需要虚构MM2S。HWH库存不是物理连接验证；静态声明、驱动运行、实板测量分别记载。哈希用于文件追溯，不是硬件身份协议，也不证明日志真实。

历史审阅保留在项目证据目录，不作为当前执行地址。已有实板结果不会因通用适配器尚未提供而被否定。
