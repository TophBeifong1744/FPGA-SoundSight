# 已复现的校验器故障与提炼

原始失败保留在项目证据归档；本页为通用方法摘要，不带固定成员、分支或接单流程。

| 故障 | 根因与修正 | 已有验证 |
|---|---|---|
| 合同IP不在HWH仍通过 | 绑定MODULE实例；不把端口、参数或IP类型当实例 | 缺DMA/控制IP负例均FAIL；层级实例使用完整路径 |
| 重复ID掩盖先前失败 | 逐条核验，任何重复均报错，不用字典静默覆盖 | 坏→好、好→坏、重复成功及重复失败均拒绝 |
| 独立包缺依赖/许可 | 包含源码、脚本、合同及授权说明；路径相对 | 离开原仓库复跑，不能依赖历史Git对象 |
| JSON大整数被浮点转换 | 整数保留精确比较，浮点使用声明容差 | 大整数差1必须检出，不扩大容差修饰失败 |

原2026-09-14及2026-10-18记录的55方法/57子测试、14次会话属于对应版本。当前执行结果见[验证状态](validation-status.md)。模拟时间不代表硬件性能；历史失败存在不等于现版仍有同一故障。
